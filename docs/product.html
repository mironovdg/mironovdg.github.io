Продукт: книга для своих и платная версия

Черновик от 25.09.2026, статусы — на 26.09.2026. Работы по режиму «Сервис» — после решения Дмитрия; конвейер для своей книги идёт уже сейчас как её доработка. Общая картина — «План проекта».

Статусы: ✅ сделано · 🔄 в работе · ⏳ в очереди · ⏸ ждёт условия · 🟡 ждёт решения Дмитрия.

1. Цель

Довести книгу до продаваемого продукта в двух режимах:

  • «Свой Claude» — ученик с подпиской Claude: движок + автоматика на его компьютере (уже работает, нужна простая установка и экономия токенов);
  • «Сервис» — ученик без Claude: книга на нашем сайте, главы пишутся на нашем сервере.

2. Ограничения, которые определяют архитектуру

  • Claude для платного сервиса в России не подходит: API официально недоступен в РФ, а подписку (Pro / Max) нельзя использовать для обслуживания других людей — она для личного пользования. Claude остаётся: для режима «Свой Claude», для разработки движка и как эталон качества.
  • Персональные данные граждан РФ (почта, голосовые записи, прогресс) — хранить на серверах в России (152-ФЗ).
  • Российские модели в раунде 2 не написали главу по правилам (лучшие — Qwen3 и GigaChat Ultra, ~3 нарушения после правки). Половина нарушений — в упражнениях, которые может строить код.

3.2. Режим «Свой Claude»

  • Установка одной командой (или одним файлом) вместо ручной инструкции; проверка установки.
  • Автоматика на новом конвейере (экономит лимиты подписки ученика в 4–5 раз).
  • Сторож автоматики: если запуск завис или упал — сообщение ученику (сейчас зависание 23.09 прошло незамеченным).

3.3. Режим «Сервис»

  • Сервер в России (Yandex Cloud): очередь заданий «написать главу», исполнитель конвейера, хранилище учеников (вместо Google Таблицы на каждого).
  • Модель — по итогам раунда 3 (см. 3.4). Варианты доступа:
  • API по токенам (Yandex AI Studio, Cloud.ru — Qwen, DeepSeek, GLM, GigaChat) — платим за фактический расход, старт без вложений;
  • своя модель на GPU-сервере — например A100 80 ГБ в immers.cloud ≈ 212 ₽/час (≈ 152 тыс. ₽/мес круглосуточно). Выгодно только при масштабе или в пакетном режиме: генерировать главы ночью 1–2 часа → ≈ 6–13 тыс. ₽/мес. Решать после раунда 3 и при > 300–500 активных учеников.
  • Ручная проверка: глава, не прошедшая проверку после правок, уходит в очередь; ученик получает её с задержкой, а не с ошибками.

6. Критерии приёмки

  • ≥ 95% глав проходят 33 проверки без человека (после не более 2 правок);
  • выборочная проверка методистом: 9 из 10 глав «годится»;
  • цена главы: Claude ≤ $1, российская модель ≤ 15 ₽;
  • глава готова ≤ 30 минут после отчёта;
  • ни одного ключа и персональных данных вне российского хранилища (для режима «Сервис»).
