Сайт: план (SEO и ИИ-поиск)

Решение Дмитрия 26.09.2026: сделать полностью готовый боевой сайт проекта с большим числом страниц, оптимизированный под поисковики (Яндекс, Google) и под ИИ-ответы (Яндекс Нейро и Алиса, ChatGPT, Perplexity, Claude, Gemini). Статус: 🟡 план ждёт правок Дмитрия; работы — после утверждения. Этот документ подробно раскрывает этапы 1–2 плана «Сервер и сайт» (решения, лендинг и справочные страницы).

Методика — по навыкам marketingskills (site-architecture, programmatic-seo, ai-seo, seo-audit, schema, copywriting, free-tools), дизайн-система — ui-ux-pro-max, проверки каждой сборки — Playwright.

2. Откуда ключевые слова

  • До запуска — Вордстат через API (tools/wordstat.py): у Метрики данных о запросах нет, пока нет сайта и посетителей. Данные 26–27.09.2026 (≈ 150 запросов) — в документе «Спрос по темам» и в таблице страниц ниже; сырые — strategy/wordstat/.
  • После запуска — Яндекс Вебмастер («Поисковые запросы»: по каким запросам показали и кликнули) и Метрика (поведение, конверсии, источники, в том числе из ИИ-сервисов). Раз в месяц — сверка: запросы, которых нет в плане, → новые страницы или разделы; страницы без показов → переписать или объединить.
  • Одна страница — один основной запрос и его хвосты; два раздела на один запрос не делаем (иначе они отнимают друг у друга место в выдаче).

6. Оптимизация под ИИ-ответы

  • Ответ сразу: под каждым заголовком H2, сформулированным как вопрос, — ответ в 40–60 слов, который понятен без остальной страницы; дальше подробности, таблицы, примеры.
  • Таблицы и списки вместо сплошного текста: формы глаголов, сравнения, шаги.
  • Факты и источники: NGSL (частотность), Britfone (британская транскрипция), шкала CEFR (Совет Европы), собственные данные книги (сколько слов за месяц, какие ошибки чаще) — с датами.
  • Автор и свежесть: на каждой странице — автор (Дмитрий: учится по своей книге с августа 2026), дата «обновлено»; страница «О проекте» с первым опытом.
  • Разметка schema.org: Organization, WebSite, BreadcrumbList на всех; Article — дневник и статьи; FAQPage — вопросы; HowTo — «как поставить звук», «как учить слова»; DefinedTerm — глаголы и слова; Course — книга; Quiz — тест уровня.
  • Файлы для ИИ: llms.txt (что за проект и главные страницы), llms-full.txt (текст ключевых страниц), beta.md (цена и условия беты).
  • Доступ роботам: разрешены YandexBot и YandexAdditional (Нейро), Googlebot и Google-Extended, GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, PerplexityBot, Bingbot.
  • Весь текст — в HTML без обязательного JavaScript: озвучка и тренажёры — поверх готового текста.
  • Присутствие вне сайта: статьи на Хабре, vc.ru и Дзене со ссылками, Telegram-канал, описания роликов — ИИ-сервисы часто цитируют сторонние площадки.

7. Технические требования

  • Статический сайт: страницы собирает Python из данных книги (как документы «₽»), без базы и CMS; сборка и проверка — одной командой.
  • Скорость: страница на телефоне — быстрее 1,5 с (LCP ≤ 2,5 с, CLS ≤ 0,1), шрифты — свои, картинки — WebP/AVIF с размерами.
  • Телефон прежде всего: ширина 375 px без горизонтальной прокрутки, кнопки ≥ 44 px, тёмная тема.
  • Доступность: семантическая разметка, подписи кнопок, контраст AA, клавиатура.
  • SEO-основа: уникальные title и description, один H1, canonical, Open Graph, sitemap по разделам, robots.txt, страница 404, перенаправление www → без www и http → https.
  • Без сети: сервис-воркер — открытые страницы и тренажёры работают без интернета (как книга).

8. Дизайн

ui-ux-pro-max подбирает дизайн-систему под «обучение языку»: стиль, палитру, пары шрифтов, правила UX. Предлагаю взять за основу стиль книги (Literata + IBM Plex, «чемодан», спокойные цвета), чтобы сайт и книга выглядели одним продуктом, и проверить его правилами ui-ux-pro-max (контраст, размеры, состояния, анти-паттерны).

9. Проверки перед каждой выкладкой (Playwright)

Скрипт проходит все страницы сборки и падает, если что-то не так:

  • каждая страница отвечает, внутренние ссылки не битые, нет страниц без входящих ссылок;
  • title 30–65 знаков и description 70–160 — уникальные; один H1; canonical на себя; разметка schema.org разбирается;
  • на 375, 768 и 1280 px нет горизонтальной прокрутки; снимки ключевых шаблонов в светлой и тёмной теме — для просмотра глазами;
  • текст виден с выключенным JavaScript; LCP и CLS в пределах нормы;
  • у картинок есть alt, у кнопок — подписи; lang="ru";
  • sitemap совпадает со списком страниц, robots.txt не закрывает нужное.

Перед запуском — ещё аудит по чек-листу seo-audit и ai-seo, отчёт — в документы «₽».
